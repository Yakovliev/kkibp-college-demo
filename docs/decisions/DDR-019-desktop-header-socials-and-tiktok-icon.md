# DDR-019: соціальні іконки лише у desktop header та уніфікована іконка TikTok

## Статус
Прийнято

## Дата
2026-07-24

## Контекст
Після адаптивної звірки рішення DDR-018 виявлено помилку у вимозі до tablet і mobile header. У цих розкладках Instagram і Facebook уже були приховані, тому окреме відображення TikTok порушувало погоджений принцип: у компактному header соціальні мережі не показуються взагалі.

Також іконка TikTok, спочатку додана до демоверсії коледжу, візуально відрізнялася від більш симетричної іконки, уже погодженої в демоверсії інституту.

## Рішення
- Сайт використовує одну стандартну тему без перемикача день/ніч. Вимкнену реалізацію нічної теми збережено в коментарях.
- У desktop/laptop header показуються Instagram, Facebook і TikTok.
- У tablet і mobile header усі соціальні іконки — Instagram, Facebook і TikTok — приховуються.
- У footer Instagram, Facebook і TikTok залишаються видимими на всіх адаптивних розкладках.
- Для TikTok у header і footer використовується той самий компактний SVG-path, що й у демоверсії інституту: `M16.5 3c.2 1.9 1.4 3.5 3.5 4.1v3.2a8.3 8.3 0 0 1-3.5-1v5.3a5.9 5.9 0 1 1-5.1-5.8V12a2.7 2.7 0 1 0 1.9 2.6V3h3.2Z`.
- TikTok веде на `https://www.tiktok.com/@studparliament_kkibp`, відкривається в новій вкладці, використовує `rel="noopener noreferrer"` і має локалізований `aria-label`.

## Альтернативи
- **Показувати TikTok окремо на tablet і mobile:** відхилено, оскільки compact header не повинен містити жодних соціальних іконок.
- **Залишити попередню іконку TikTok:** відхилено через менш симетричне сприйняття поруч з іншими службовими іконками.
- **Приховати TikTok у footer на compact-розкладках:** відхилено, оскільки footer залишається основним місцем для повного набору соціальних мереж на всіх пристроях.

## Наслідки
- DDR-019 замінює DDR-018 як чинне рішення щодо теми та адаптивного розміщення TikTok.
- У CSS `.header-tiktok` має бути прихованим за замовчуванням і відображатися лише у desktop/laptop breakpoint від `1100px`.
- У Playwright потрібно перевіряти видимість TikTok у header на laptop/wide, його прихований стан разом з Instagram і Facebook на mobile/tablet та видимість TikTok у footer на всіх адаптивних проєктах.
- Майбутня CMS або production-реалізація має керувати соціальними посиланнями глобально, але дотримуватися цієї адаптивної видимості.
